# Mnemo Writes

A minimal static author-site foundation. All copy is placeholder text; no biography or writing has been supplied.

## Local preview

From this directory, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000. There are no build steps, dependencies, external fonts, scripts, or analytics.

`index.html` contains the page content, `styles.css` provides responsive light and dark layouts, and `favicon.svg` supplies the site icon.

## GitHub Pages

This is the Mnemo Writes GitHub Pages repository. The review branch `mnemo-writes/site` keeps proposed changes ready for review. Once approved and merged into the branch configured as the GitHub Pages source, those changes can appear on the site. This branch does not publish by itself.
